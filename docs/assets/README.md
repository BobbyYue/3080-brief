# Documentation assets

This folder contains the visuals used by the repository README and source-linked worked examples.

- `claude-code-comparison.png`: the README's original-source versus 3080-output comparison.
- `claude-code-comparison.html`: the reproducible layout used to render that comparison.
- `claude-code-session-value.svg`: the worked example's auditable one-picture summary.
- `social-preview.png` and `social-preview.svg`: repository preview variants.

`claude-code-original-excerpt.jpg` is a limited screenshot of [Maximizing the value of your Claude Code sessions](https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions), used only to identify and comment on the source in the comparison.
